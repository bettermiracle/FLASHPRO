# FlashPro

A simple Android flashlight app with a professional dark interface.

## Current version
- One-tap torch ON/OFF
- Detects whether the phone has a camera flash
- Turns the torch off when the app leaves the foreground
- Premium section priced at ₦2,000 (checkout not yet connected)

## Build
Open the project in Android Studio, allow Gradle to sync, then run the `app` configuration on an Android phone.

## Next development stage
Connect a legitimate Google Play Billing subscription or one-time premium purchase, then add premium features such as SOS, strobe and brightness controls.
